# Case Review Automation
## 工单自动分类与运营分析工作流

本项目源于实际业务中的工单整理与运营分析需求，将数据导入、规则分类、AI 辅助复核、人工确认和报告输出连接为一条工作流。

项目重点包括：
- 将业务判断整理为明确的分类规则。
- 保留初始分类与复核结果，记录修改依据。
- 在结果回写前进行数据与分类校验。
- 通过可视化统计和报告支持运营分析。

## 业务背景

在企业服务运营中，运营人员需要定期整理业务系统导出的工单数据，分析需求来源、活动类型和业务主题，并形成统计报告。

这项工作包含多层判断：记录服务于内部协作还是外部需求、当前属于哪种处理活动，以及具体涉及哪些业务主题。这些维度的适用范围不同，需要分别定义规则。

部分记录可以依据明确规则分类，另一些则存在描述不完整、关键词歧义或多个主题同时出现的情况，需要补充上下文并进行复核。分类结果还要继续用于数据汇总、图表制作与报告交付。

## 项目目标

- **统一分类口径：** 将业务经验整理为明确的分类维度、判断顺序和例外条件，提高结果的一致性。
- **减少重复操作：** 将数据整理、规则分类、结果更新和报告生成连接起来，减少反复复制与手动处理。
- **支持疑难案例复核：** 结合独立 AI 工具与人工判断处理不明确的记录，保留初始分类、最终结果及关键词依据。
- **保障结果更新的一致性：** 在复核结果回写前检查记录对应关系、标签合法性和数据状态。
- **支持运营分析：** 将确认后的分类结果转化为可视化统计与报告，并明确主主题和多标签统计的计数方式。

## 公开版设计

### 工作流程

#### 1. 数据导入与整理

支持导入 Excel 或 CSV 文件，将表格中的记录编号、标题、描述等字段对应到工具中，识别缺少编号、重复记录等情况，为后续分类准备数据。

#### 2. 设置分类维度与标准

用户根据业务需求，定义一个或多个分类维度，并为各维度下的具体分类设置分类名称、分类原则、优先级和组合方式。

不同维度分别判断，同一条记录可以在多个维度下获得分类结果。

#### 3. 初步分类

通过可执行规则处理能够明确判断的记录，生成初步分类结果，并保留匹配依据。

需要结合业务语义判断、缺少依据或存在冲突的记录，进入后续复核环节。

#### 4. AI 辅助复核与人工确认

将待复核记录及分类标准导出，在支持 MCP 的独立 AI 工具中，通过已配置并获授权的 MCP 服务连接相关数据平台，按需读取与当前记录有关的补充上下文。

AI 结合分类原则、原始记录和补充信息进行分析，提出分类建议，再由人工确认。

初始分类与复核结果分别保留，便于比较修改并查看分类依据。对于上下文不足或仍存在冲突的分类，允许留空，保留待确认状态。

#### 5. 复核结果校验与更新

导回复核结果时，检查记录编号是否对应、分类是否属于用户定义的范围、组合方式是否符合设置，以及数据是否已发生变化。

通过校验后更新结果；存在冲突或异常的记录保留待处理，避免直接覆盖。

#### 6. 可视化分析与报告输出

按照用户定义的分类维度汇总结果，生成分类分布和统计图表，并支持表格、PPT 与 PDF 导出。

对于允许多标签的维度，提供两种统计口径：

- **主分类统计：** 每条记录计入一个主分类。
- **全部分类统计：** 统计每条记录的全部有效分类，一条记录可以计入多个分类。

统计时注明计数方式，并单独展示待确认记录，帮助使用者理解分类结果与统计数量之间的关系。

### 分类设计

#### 按业务定义分类维度

分类维度表示“按什么角度分类”，具体分类表示该维度下可以使用的标签。

用户可以根据业务需求定义一个或多个维度。例如：

| 应用场景 | 分类维度示例 | 具体分类示例 |
| --- | --- | --- |
| 需求整理 | 需求类型 | 咨询、申请、反馈 |
| 内容管理 | 内容形式 | 文案、图片、视频 |
| 资料归档 | 资料类别 | 操作指南、参考资料、常见问题 |

以上仅为通用示例，用户可以根据自己的业务重新定义。

同一条记录可以在不同维度下分别分类，各维度的分类标准独立管理。

#### 可配置的分类标准

每个具体分类包含以下四项设置：

| 设置项 | 说明 |
| --- | --- |
| 分类名称 | 定义最终输出的分类标签 |
| 分类原则 | 说明分类的业务含义，以及什么情况下应归入该类 |
| 优先级 | 多个分类同时符合时，决定优先采用哪一类，支持通过排序调整 |
| 组合方式 | 设置该分类单独使用，或允许与指定分类同时使用 |

分类原则用于指导人工及 AI 辅助判断；优先级和组合方式用于确定同一维度内多个分类同时符合时的处理方式。

程序自动分类由可执行规则完成。需要进一步理解业务语义的记录，进入 AI 辅助复核环节；在相关 MCP 服务可用时，AI 可以获取补充上下文，辅助完成判断，并由人工确认最终结果。

整体工作流将规则分类、MCP 上下文获取、AI 辅助分析与人工确认相结合，使分类既有明确标准，也能参考实际业务信息。
